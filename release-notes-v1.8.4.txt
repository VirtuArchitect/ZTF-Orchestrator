ZTF-Orchestrator v1.8.4
=======================

Release date: 2026-09-21

Summary
-------
- Adds automated Drift Detection policies so operators can schedule baseline
  comparisons and still run policies on demand.
- Aligns runtime, demo, appliance, and documentation metadata to the v1.8.4
  appliance update baseline.
- Corrects classic Foundation VM network-service serialization so controlled
  image_nodes submissions match the Foundation 5.11 native payload schema.

Validation

- python -m pytest tests/test_foundation_vm_backend.py -q
- python -m pytest tests/test_api.py -q -k "foundation_vm or classic_foundation"
- python -m pytest tests/test_release_integrity.py -q
- python -m pytest tests/ -q -x
