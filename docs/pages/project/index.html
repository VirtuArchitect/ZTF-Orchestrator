Repository status · 19 November 2026

Current console, clear release channels

Latest reviewed application source: db16219. YAML Studio now brings cluster context, guided forms, authoring checks and reviewed pipeline handoff into one workspace.

v1.8.5-rc1 is the current prerelease. v1.8.4 remains the latest stable release. Source updates and versioned appliance packages are separate; check the exact package version before updating.

Capabilities

From cluster build to recovery rehearsal

01

Deploy clusters

Prepare Foundation VM or Foundation Central deployment configurations. Review image inventory, credentials and targets before approved imaging and cluster creation.

Deployment guide ↗
02

Operate and govern

Review approvals, session activity and durable job logs. See the actual pipeline step and failed stage, explicit PE collection errors and evidence age.

Operations guide ↗
03

Prepare for recovery

Use Recover Cluster or Resume Recovery with versioned profiles, clear stage status and preserved completed work. A step 08-only PC registration retry requires reconciliation and fresh health evidence.

Recovery guide ↗
04

Author configuration in YAML Studio

Select a datacenter, cluster and task. Review generated YAML, validate syntax, workflow shape and credential references, then save and review a pipeline handoff. Authoring never starts a job.

YAML Studio operator guide ↗
05

Plan PE-direct configuration

AHV Uplink Migration supports per-host NIC assignments through pinned CVM SSH. DARE supports PE-direct enablement with an existing Local KMS. Both preserve independent approval and verification; live writes default to off pending environment validation.

Uplink migration guide ↗DARE guide ↗
06

Maintain the appliance

Review storage, import an offline update ZIP, check readiness and approve the exact version. Follow backup, install and verification stages, retaining a verified backup pair and rollback image.

Guided appliance updates ↗

Credential and Config Files groups organize saved references; they do not select credentials automatically or create access boundaries. PE-direct TLS exceptions are per-run, reasoned, independently approved and audited. Uplink SSH host-key verification remains required. Enabling DARE is irreversible; appliance rollback does not disable encryption.
