Under Configure, open Enable Data-at-Rest Encryption. Choose PE direct and enter the expected cluster UUID, PE endpoint and saved credential reference. This path uses Prism Element and an existing Local KMS; it does not require Prism Central or SSH. It is not an external key-manager conversion tool.

Keep certificate verification enabled. A permitted temporary exception needs an explicit reason, independent approval and an audit record. HTTPS remains encrypted, but bypassing certificate verification removes that certificate-based identity check. The exception applies to this operation and does not change global trust or other workflows.

Run read-only discovery. Verify cluster identity, complete healthy membership, supported software-encryption state and the reported Local KMS. Review licensing, platform support, other encryption tasks and key-backup ownership. Missing, partial or unsupported states block the operation rather than being converted automatically.

Software encryption cannot be disabled after enablement. Review the exact plan and obtain approval from a different administrator. Live writes default to off until the installed version and hardware have been validated. In an enabled environment, the exact confirmation precedes fresh identity, health and state checks and one request.

PE configuration readback and background encryption monitoring are separate from proof that keys can be recovered. Preserve and verify key backups outside the appliance. If submission or verification is uncertain, inspect actual PE state before another request. Rolling back the Orchestrator does not turn encryption off.
