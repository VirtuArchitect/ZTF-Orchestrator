In Administration, Setup and Install, verify the compatible ZTF one point x runtime. Framework status starts as Checking framework while detection runs. Installed framework files do not prove cluster health. Retained NKP or two point x binaries do not make their retired console execution available.

Open Users, then Sessions as an administrator. Three signed-in users and five sessions can represent several sign-ins by the same account. Recently active means recorded interaction within five minutes; an unexpired session is not proof that a person is currently using the console.

Review username, sign-in role and time, last activity and expiry. Passive polling does not itself prove activity, and activity does not extend expiry. To revoke one session, review its identifier and confirmation, then inspect the audit record. Do not confuse revocation with deleting the user account.

Back up configuration and the matching database and application data through the approved maintenance procedure. Keep verified copies outside the appliance. Preserve credentials, pipelines, approval records and recovery progress together. Do not use unrelated backup halves as a restore pair.

For support, record the running image and health build identity, relevant job identifiers and safe audit evidence. A downloaded update is not an installed update. Keep passwords, private keys and customer details out of screenshots and exported diagnostics. Use the current written guide for the version-specific procedure.
