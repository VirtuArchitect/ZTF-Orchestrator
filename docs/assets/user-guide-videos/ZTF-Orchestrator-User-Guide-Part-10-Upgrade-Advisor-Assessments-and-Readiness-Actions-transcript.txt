Upgrade Advisor is a read-only risk assessment, not an upgrade executor. For Cluster A, enter the intended current and target versions. Use saved PE and optional PC credential references for the supported inventory reads. Keep certificate verification selected by default.

The PE and PC inventory controls have separate request-scoped TLS settings. An administrator can make a deliberate temporary exception where permitted. The exception is audited and retained with collection results, and verification resets afterward. It does not change recovery health, drift or other workflows' trust settings.

Review what the collection actually returned and what remains Unknown. A failed read is not a version value. NCC, LCM prechecks, firmware, Foundation and compatibility evidence are not all collected automatically. Supply missing information through the appropriate independent procedure and retain its source.

Run the assessment and open each finding. Check its source, affected version or feature, severity and recommended action. A saved declaration that release notes or compatibility were reviewed is not an automatic vendor check. Resolve the finding through its documented evidence, not by changing a label to look ready.

Save the assessment snapshot with its inputs, collection provenance and findings. Reassess when the target or evidence changes. Use the result alongside the vendor upgrade process and site change approval. It does not certify every hardware combination or submit an upgrade.
