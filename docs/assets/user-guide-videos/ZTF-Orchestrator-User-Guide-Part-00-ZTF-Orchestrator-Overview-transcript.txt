A new cluster needs more than an installer. Its physical nodes need approved images and addresses, its services need configuration, and its recovery process needs a reviewed plan. ZTF Orchestrator brings those activities into one browser console. This walkthrough follows a simulated Cluster A; it changes no infrastructure.

The Orchestrator stores reviewed YAML, credential references, approvals and job evidence. ZTF one point x remains the workflow and pipeline executor. Foundation VM performs the imaging and cluster formation. Prism and guarded specialist adapters perform their supported target actions. The Orchestrator coordinates those systems; it does not replace Foundation.

Start Here offers deployment, configuration, recovery, monitoring and saved automation. YAML Studio helps prepare a configuration and hand it to a pipeline. Saving a file starts no job. Successful authoring checks do not prove that a password works or that a target is ready.

Recovery profiles preserve deployment and pipeline snapshots. Resume an existing recovery to retain approvals and completed work. Monitoring distinguishes recorded health, failed collection and expired evidence. Inspect the result behind a status before accepting the cluster for workload restoration through your backup platform.

Native pipeline opt-in, NKP and ZTF two point x console execution are retired. Historical records remain. Specialist changes keep their own approval and verification gates. This release is a candidate, and simulated videos do not establish hardware compatibility. Begin with Start Here and the current written guide.
