# Deployment process diagrams

Revision 3 is aligned to the Administrator and User Guide dated 27 October 2026
for v1.8.5-rc1. It covers design, guided preparation, service-specific execution,
post-configuration, verification and operational acceptance.

- [Full-resolution PNG](cluster-deployment-v3.png), 6400 x 3600 pixels.

- [Text equivalent and related procedures](../../cluster-deployment-process.md).

These are process illustrations rather than console screenshots or evidence of
a new live deployment. They retain pipeline approval boundaries, verification
gates, explicit manual/evidence-only controls and feature-specific limits.
No target identities, passwords or private environment details are included.
