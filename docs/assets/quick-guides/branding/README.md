# Standard ZTF Operational Quick Guide Format

The cover is the unchanged first page of **ZTF-Orchestrator Quick Guide -
Multiple Cluster Deployment Planning.pdf**, rendered at three times its native
Letter-page resolution. It retains the original zerotouch logo, Operational
Quick Guides title and infrastructure artwork. No new artwork or replacement
logo was created.

The corrected editions use a full-page cover without a footer, followed by a
separate body section in the established Quick Guide format:

- US Letter portrait; body margins 49/51 pt left/right and 70/50 pt top/bottom.
- Arial 11 pt body; 20 pt bold page titles and 15 pt bold subheadings.
- `ZTF-Orchestrator | Team Operational Quick Guides` running header.
- Version, explicit source revision, month and physical page number in the footer.
- Navy `#17365D` table headings, white header text and light body rows.
- Original editable procedures, links, guide IDs and simulated task screenshots retained.

The initial host/CVM password Quick Guide supplies the matching editable style
reference. Both reference files and all earlier collection editions remain
unchanged. The [branding manifest](../../../manuals/workflow-script-quick-guides-branding.json)
records reference hashes and corrected Word/PDF hashes. This is a format
correction dated **21 November 2026**; source review and screenshot provenance
remain pinned to `79c3ecc` on 20 November 2026.
