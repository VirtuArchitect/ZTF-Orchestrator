# ZTF Orchestrator Documentation Collection

This collection brings the maintained operator guides, task procedures, runbooks, architecture, governance and API references into one PDF library. Current execution and transport guidance was reviewed on 21 November 2026 against application source `db162199f8b89a2f1a82b21581a28a7bc204ef59`. The release remains v1.8.5-rc1 prerelease. Match each document to the exact installed build.

Use Getting started to choose an outcome, then choose the relevant task or operational runbook. Technical and Native Foundation references describe their stated interfaces and review boundaries. A planning review is not hardware execution or production acceptance. Native Foundation Deploy is distinct from the retired Native pipeline executor option. NKP and ZTF 2.x console setup and execution are retired.

The collection preserves the ZTF cover and document format, source identifiers, original review boundaries, and labelled simulated figures. Earlier manuals and retired integration references remain in the historical filter. An older edition is not silently presented as current. Private configuration packs, dated lab results and superseded publication evidence are excluded from current guidance. The source register records their disposition.

## Reading and download choices

Browse the [documentation website](https://virtuarchitect.github.io/ZTF-Orchestrator/documentation/) to search by title, task, topic or API name. Open a PDF in the embedded reader or use its Open PDF and Download PDF links. Use the PDF viewer's Find command for text inside the selected document. The separate [video tutorial collection](https://virtuarchitect.github.io/ZTF-Orchestrator/tutorials/) remains available.
