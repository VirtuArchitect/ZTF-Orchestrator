# UAT Evidence

Current release marker: `v1.7.8`.

Each controlled UAT record should capture:

- ZTF-Orchestrator version and commit/tag.
- Deployment mode and storage backend.
- Operator and approver.
- Config/profile/package hash.
- Approval ID where required.
- Job ID and terminal state.
- Validation result.
- Audit events.
- Target-side confirmation or simulator/lab boundary.
- Backup, restore, or DR reference where applicable.

See [UAT Evidence Checklist](../uat-evidence-checklist.md) for the detailed
field list.
