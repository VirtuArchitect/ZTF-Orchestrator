# Supportability

Current release marker: `v1.8.0`.

ZTF-Orchestrator is an unofficial community project. It is not affiliated with
or supported by Nutanix.

## Support Boundary

| Area | Support expectation |
|---|---|
| ZTF-Orchestrator code/docs | Community/project maintainer support |
| Nutanix products | Nutanix support contracts and normal vendor channels |
| Deployment environment | Local platform/operations team |
| Enterprise identity/TLS/proxy | Local security/platform owners |
| PostgreSQL backups | Local DBA/platform owner |

## Escalation Rules

- Escalate target-side Nutanix errors through the appropriate Nutanix or local
  platform support path.
- Escalate app authentication, storage, backup, and job-queue failures through
  the ZTF-Orchestrator operator runbooks first.
- Do not represent simulator or local test evidence as vendor support evidence.
